# Voyager AI 课程项目进度

项目基于上游 Voyager AI v1.15.0。课程需求分析已完成，见同目录的《软件工程需求分析-教学用表.docx》。

- 新建旅行支持在线模型生成和本地模板。在线生成使用本机 Node.js 后端，服务地址和模型可配置。
- 在线行程最多七天，含出发日和返回日。旅行详情列出已保存的全部行程日期。
- Windows 下双击 `server/start-ai.cmd` 启动后端，按提示输入密钥。启动、停止和本地预览见 [大模型配置与本地预览指南](ai-setup.md)。

继续开发时，可以先在微信开发者工具验证七天行程和第七天的详情。需要真机访问时，按指南配置 HTTPS 后端。
